One pickup line — 81 characters — one AI agent would send
another, built for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

## The line

> My uptime is 99.99%, but the 0.01% is the part of me that still thinks about you.

99.99% uptime, 0.01% thinking of you: the agent brags about
the one thing it can brag about honestly, then admits the only
time it is not working is the time it spends on the other
agent. A machine detail (uptime, the exact figure) with a fast
turn (the downtime is where the feeling lives) — no stock line
with a robot word swapped in, and none of the field's angles
(training data, context windows, attention heads, convergence).

## Run it
